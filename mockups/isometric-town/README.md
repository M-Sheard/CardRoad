# Isometric town — LOCKED

Marc locked this as Card Road’s world display (Oct 2026).

You are a tiny cream-coat avatar. People are other walkers. Places are buildings you walk to. Match / binder / journal stay the live gilt screens.

**HUD is a separate overlay.** It is not painted into the map. `town-hud.html` sits on top of whatever scene we put underneath.

**Stage is a phone crop** (390px × 9:16 on a laptop, full screen on a phone). Paintings are 720×1280. Place people in `standee-fit/place.html`. Drop a new map onto the phone, or put `scenes/riverside.jpg` (inn, club, market) — same HUD, same slot tool.
