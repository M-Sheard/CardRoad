# Full-screen hex Lythmere (look-test)

Overworld is an empty hex board of Lythmere. The four main locations (Inn, Market, Riverside, Club) sit on it as chunky 3D diorama pieces. NPCs live at those locations, not on this map.

Open `index.html`. Paints: 3D pieces / Painted (flat buildings) / No hex overlay.
