# Town HUD overlay

The HUD is its own layer. It sits on top of whatever map we put underneath and resizes with the viewport.

- Overlay source: `town-hud.html` (`?layer=hud` / `?layer=scene` / default both)
- Hardware: `hud/paper_corner.png`, `hud/paper_seal.png` (from live v96 — not `date_frame_*` scrolls)
