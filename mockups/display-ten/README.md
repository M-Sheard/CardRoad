# Ten ways to display Card Road

Fresh-slate screen ideas. Not people-in-a-painted-street. Same game (living card world, 3×3 matches, calendar, collection). Different shell.

1. **Travelling desk** — map, journal, newspaper, binder, challenge notes. You handle objects, not a street.
2. **Across the table** — first-person match. You sit opposite someone in a room.
3. **Toy theatre** — proscenium, backcloth, paper figures. The backdrop is allowed to be a backdrop.
4. **Side-on 2D walk** — adventure-game street, ground line, walk left–right.
5. **3D village** — you walk a real town. Different product if we leave the web core.
6. **Board and pawns** — printed map, wooden pieces, match as an inset.
7. **Comic book** — the week is a page of panels. A match is a splash.
8. **World is a deck** — towns and people are cards in a spread.
9. **Pop-up book** — turn the page, a paper town stands up.
10. **Almanac home** — newspaper, directory, fixtures. You read the world, then sit a match.

Live game unchanged. These are look-tests only.
